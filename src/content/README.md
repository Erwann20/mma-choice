# content/

Contenu du jeu en **JSON pur**, validé par les schémas Zod de `src/schema` (AD-4).

- `events/*.json` — Événements de carrière
- `divisions.json` — divisions de poids UFC
- `starting-criteria.json` — origines / styles / entourages
- `opponent-archetypes.json` — gabarits d'adversaire (les instances sont générées par le moteur)

Ajouter du contenu = ajouter du JSON validé, **sans toucher au code** moteur/UI.
Rempli à partir de la Story 1.3.
