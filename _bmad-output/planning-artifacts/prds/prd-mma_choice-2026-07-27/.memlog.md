- (decision) Create intent: PRD for MMA Choice — a choice-driven MMA fighter-career web game modeled on destinyeleven.com (football) but reskinned to MMA. Project dir mma_choice confirmed = MMA, not football.
- (event) Research digest on Destiny Eleven captured: text-based interactive fiction (not match-sim) + light stat sim underneath; career age 16->retirement season-by-season via narrative choices adjusting stats (Form/Morale/Charisma/Stats); career = a few minutes, snackable/replayable; score/100; 36 badges, leaderboards (Panthéon), Legend Mode; pure web app, no account, browser persistence, mobile-friendly; free-to-play no ads, meta-currency 'tokens' for unlocks (real-money IAP unverified). Launched Jul 2026, 150k players in 2 days.
- (decision) V1 scope: single fighter-career mode. Flow: create fighter -> choose country -> starting life/entourage criteria -> choices across career determine outcome (bad fighter / good / GOAT). Key differentiators vs Destiny Eleven: MANY more choice-questions and high career variety (a run must not always be the same / low redundancy). Core challenge & top priority per user: the DATA — a large, well-organized library of career events. No existing inputs (greenfield).
- (decision) Calibration: stakes = side-project/test (lean PRD, ~2 pages, focus on event-engine essentials). Working mode = Coaching path, entry point = Journey-led (proposed & starting there) since consumer game; then pivot to event-system capabilities. Assumptions posed to user: web app / mobile-friendly / zero-friction like D11 (no mandatory account, browser save, free), social+leaderboards deferred to phase 2; team = solo/personal build.
- (decision) Journey UJ-1 (Karim, 19, mobile via TikTok link). Home = 3 modes: (1) 'Faire ma carriere' (create-your-own, the core), (2) 'Revivre la carriere' (replay a real/existing fighter's career; rotates weekly = Legend/weekly-challenge equiv), (3) 'Mission du jour' (daily: take a fighter with imposed starting criteria/constraints). Create fighter: choose country, starting age, starting criteria (novice/agile... user hands me the pen to invent), entourage, etc. Career starts with choices (e.g. enter IMMAF amateur circuit); fights also present choices. Rhythm = YEAR by year. Player sees stats evolve from choices. Career ends when fighter is too old to fight (age-out).
- (decision) Model additions per user: (1) DIVISIONS DE POIDS essential (gate opponents/titles; weight-cut events affecting health). (2) ARGENT/SPONSORS as resource meta (fight purses + sponsor deals gated by hype; money reinvested into camps/training -> stats). (3) RESEAUX SOCIAUX / followers as a meta gauge (grows via wins, trash talk, controversy; unlocks sponsors & bigger fights; backlash risk). Combat model = HYBRID: driven PRIMARILY by choices BUT modulated by stats + opponent level. Key mechanic: outcome has DEGREES / 'manner of victory' — e.g. vs a weak opponent ('plouc') even a bad choice can still WIN, but ugly / not impressively (low hype gain). So result = f(choice quality, stat gap vs opponent) producing win-dominant / win-ugly / lose, feeding Reputation/Hype differently.
- (decision) End-game: career score /100 approved (criteria: ceintures, qualite des victoires, divisions conquises/double-champ, longevite, legacy = Followers/Reputation a la retraite; final recap ranks player all-time). TONE = realistic/credible (real division names, tough career), not cartoon/exaggerated. Enough gathered -> drafting lean V1 PRD now.
- (event) Lean V1 PRD drafted (14 FRs across 6 features; event engine = FR-7/8/9 as core). Adapt-in: consumer game shape (IA/3 modes, tone=realistic, platform web/mobile zero-friction, monetization deferred). SMs with counter-metrics. 6 open questions, 4 assumptions indexed.
